6. VOICE INTERVIEWER (v2) — HOW IT WORKS
================================================================================
  Loop: AI question spoken (SpeechSynthesisUtterance) -> mic auto-starts (webkitSpeechRecognition,
  continuous + interim results) -> live transcript shown & editable -> Submit -> Gemini evaluates
  (backend) -> AI speaks one-sentence feedback -> next question spoken -> ... -> final report
  (score, verdict, technical/communication/confidence, strengths, mistakes, improvements,
  recommendations, per-question).
  Controls: Start Interview, Repeat question, Mic on/off, Submit answer, Stop interview
  (Stop generates a report for answered questions via /interview/finish).
  States: speaking, listening, processing, idle (mic paused), error; mic permission warnings.
  Fallbacks: unsupported browser / denied mic / no mic -> type answers in the same box.
  Best in Chrome or Edge (SpeechRecognition). Requires HTTPS (the preview URL is HTTPS).

6b. v3 CHANGES — AUTO-SUBMIT, VOICE COACH, ERROR FIX
================================================================================
  BUG (errors after Submit): root cause = Gemini FREE-TIER RATE LIMIT (HTTP 429 "You exceeded your
  current quota") on gemini-3-flash-preview when several AI calls happen within a minute
  (answer evaluation + next question + final report). Backend returned 503.
  FIX: ai.py now tries a chain of Gemini models on the same key, each with its own free quota:
       gemini-3-flash-preview -> gemini-3.5-flash -> gemini-3.6-flash -> gemini-3.7-flash -> gemini-3.8-flash
       A model that returns 429 is skipped for 60s. Env: GEMINI_FALLBACK_MODELS.
       Frontend auto-retries a failed answer once after 4s, keeps your answer, de-duplicates toasts.
       Speech fixes: speak() no longer hangs if the browser never fires 'onend' (safety timeout);
       old speech can no longer re-open the mic during evaluation (askToken guard);
       double submit is blocked.
  AUTO-SUBMIT: while listening, every speech-recognition result marks "activity". When you have said
       at least 2 words and stay silent for 2s / 3s (default) / 5s (selectable), the answer submits
       automatically. A yellow countdown bar shows before it fires; keep talking to cancel it.
       Toggle "Auto-submit when I stop talking" to go back to manual Submit. Typing in the answer box
       stops the mic (manual mode for that answer).
  VOICE ANSWER COACH: frontend sends per-answer metrics {words, duration_sec, long_pauses (>2s gaps),
       longest_pause_sec}; backend counts filler words (um, uh, erm, hmm, like, you know, basically,
       actually, literally, I mean, kind of, sort of, so yeah, okay so), computes words-per-minute and
       pace label (<100 too slow, 100-165 good, >165 too fast). Report shows pace, filler totals + top
       fillers, long pauses, per-question table and AI "delivery_feedback" tips.
       Note: browsers often drop "um/uh" from transcripts, so real filler counts may be higher.
  API: POST /interview/answer now accepts optional "metrics"; report adds "voice_coach" + "delivery_feedback".
